# 📚 Грамматика (справочник)

Накапливается по мере занятий — только то, что реально нужно для разговора.
Без огромных таблиц: короткое правило + примеры.

## Алфавит и произношение

Сербский пишется и **латиницей**, и **кириллицей** — один к одному, буква в букву.
Как слышится, так и пишется (фонетический принцип).

Особые буквы (латиница → кириллица → звук):
- `č` → ч → твёрдое «ч» (как русское ч в «чай»)
- `ć` → ћ → мягкое «чь» (мягче, ближе к «ть»)
- `š` → ш → ш
- `ž` → ж → ж
- `dž` → џ → твёрдое «дж»
- `đ` → ђ → мягкое «джь»
- `j` → ј → й
- `lj` → љ → ль, `nj` → њ → нь

## Правила по урокам

Новые заметки добавляются в конец — по одному правилу за урок. Когда раздел
разрастётся (~25+ правил), Claude перегруппирует его по темам: падежи,
глаголы, предлоги, вежливость.

### Vokativ — обращение по имени (урок 1)

Когда обращаешься к человеку по имени, окончание меняется:
- Мужские имена на согласный: **Jegor → Jegore**, Ivan → Ivane
- Мужские имена на -o/-e: **Marko → Marko** (без изменений)

Пока просто запоминай на слух — правило придёт само.

### Глагол «быть» — короткие формы (понадобится сразу)

| | |
|---|---|
| ja **sam** | я есть |
| ti **si** | ты есть |
| on/ona **je** | он/она есть |
| mi **smo** | мы есть |
| vi **ste** | вы есть |
| oni **su** | они есть |

Пример: `Ja sam Marko.` — Я Марко. `Kako si?` — Как ты? (букв. «как ты есть»).

### Аккузатив после volim — «люблю что?» (урок 2)

После **volim** существительное стоит в аккузативе (винительный падеж).
Для большинства слов женского рода: окончание **-u**:
- muzik**a** → Volim muzik**u**
- košark**a** → Volim košark**u**

Глагольная конструкция «люблю делать»: **volim da + глагол**:
- Volim da igram košarku. — Я люблю играть в баскетбол.
- Volim da slušam muziku. — Я люблю слушать музыку.

### Предлог iz — «из» (урок 3)

**iz** + родительный падеж (генитив) страны/города:
- Ja sam iz Rusije. — Я из России. (Rusija → Rusije)
- Ja sam iz Srbije. — Я из Сербии. (Srbija → Srbije)
- Ja sam iz Moskve. — Я из Москвы. (Moskva → Moskve)

Закономерность: -a → -e (как в русском -а → -и, но проще)

### Счёт лет — imam + godina/godine/godinu (урок 2–3)

- imam 1 godin**u** (аккузатив ед.ч.)
- imam 2/3/4 godin**e** (генитив ед.ч.)
- imam 5+ godin**a** (генитив мн.ч.)
- Числа 21, 31, 41... → как 1: **godinu**
- Числа 22–24, 32–34... → как 2–4: **godine**

### Аккузатив при заказе — «jednu + существительное» (урок 4)

При заказе (molim, hoću) существительные женского рода стоят в аккузативе (-a → -u):
- kaf**a** → jednu kaf**u**, molim
- vod**a** → jednu vod**u**, molim
- pljeskavic**a** → jednu pljeskavic**u**

Прилагательное тоже меняется: velik**a** → velik**u** pljeskavicu.
Правило то же, что после volim — аккузатив везде одинаковый.

### Аккузатив при покупке — «daj mi / hoću + существительное» (урок 5)

То же правило работает в магазине — после daj mi, hoću, treba mi:
- jabuk**a** → Daj mi jabuk**u**
- šargarep**a** → Hoću jednu šargarep**u**
- vod**a** → Treba mi vod**a** (treba mi — особый оборот, часто без аккузатива)

Ученик интуитивно использовал аккузатив без объяснения правила — хороший знак!

### Время: sat / sata / sati (урок 6)

Аналогично «год» в русском (час, часа, часов):
- 1 → **sat** (jedan sat)
- 2–4 → **sata** (dva, tri, četiri sata)
- 5+ → **sati** (pet sati)

**Который час:** `Koliko je sati?`
**В котором часу:** `U koliko sati?` → `U tri sata.` (предлог **u** = «в»)
**Половина:** `pola + следующий час` → pola tri = 2:30 (как «пол третьего» в русском!)
**И пол:** `dva i po` = 2:30 (разговорный вариант)

### Возвратные глаголы — «se» обязательно (урок 7)

Некоторые глаголы требуют частицы **se** — без неё смысл меняется или фраза ломается:
- **vidimo se** = увидимся (друг друга), **nalazimo se** = встречаемся
- Без se: «vidimo» = мы видим (что-то), «nalazimo» = мы находим (что-то)

Пример: `Vidimo se u sredu!` — Увидимся в среду!

### Императив для объяснения дороги (урок 7)

Вежливые формы (вы):
- **Idite** *(и́дите)* — идите
- **Skrenite** *(скре́ните)* — поверните

Конструкция: `Idite pravo, pa skrenite levo.` — Идите прямо, потом поверните налево.
**pa** = «потом / а потом» (связка в инструкциях)

### Семья: imam/nemam + аккузатив (урок 8)

Чтобы сказать «у меня есть»: **imam** + существительное в аккузативе:
- *Imam brata.* — У меня есть брат. (brat → brata)
- *Imam sestru.* — У меня есть сестра. (sestra → sestru)
- *Nemam sestru.* — У меня нет сестры.

Сколько: **imam dva brata** — у меня два брата (после dva — генитив ед.ч. = brata).

### Неправильное множественное: brat → braća (урок 8)

- Один: **brat** *(брат)*
- Двое+: **braća** *(бра́ћа)* — братья

Запомнить отдельно! «Brata» = генитив единственного числа (не множественное).

### Локатив vs генитив: где vs откуда (урок 8)

- **iz + генитив** = откуда: *iz Rusije*, *iz Srbije*, *iz Beograda*
- **u + локатив** = где: *u Rusiji*, *u Srbiji*, *u Beogradu*

Закономерность: Rusij**a** → из = Rusij**e** / в = Rusij**i**
Похоже, но окончание разное — -e (откуда) vs -i (где).

### Na vs U — где находится (урок 6)

- **u** = внутри закрытого помещения: u kafiću, u prodavnici, u školi
- **na** = открытое место или мероприятие: na pijaci, na poslu, na ulici

### Вежливость: извини vs изvinite (урок 5)

- **Izvini** — к другу, на «ты» (ты-форма)
- **Izvinite** — к незнакомым, официантам, продавцам (вы-форма)

Аналогично русскому: «извини» (ты) / «извините» (вы).

### Настоящее время: личные окончания (урок 9)

Два основных типа глаголов по окончанию 1-го лица:

**-im группа** (radi**ti** → rad**im**):
ja rad**im**, ti rad**iš**, on/ona rad**i**, mi rad**imo**, vi rad**ite**, oni rad**e**

**-em группа** (usta**jati** → usta**jem**):
ja usta**jem**, ti usta**ješ**, on/ona usta**je**, mi usta**jemo**, vi usta**jete**, oni usta**ju**

Частая ошибка: перепутать «я» и «они» — окончания похожи по написанию, но разные:
- ja završav**am** (я заканчиваю) ≠ oni završava**ju** (они заканчивают)

### Kod kuće / od kuće — «дома» (урок 9)

Для «работать из дома» / «быть дома» сербский использует **kod kuće** или **od kuće**,
а не дословное «u kući» (внутри дома — звучит слишком буквально):
- Radim od kuće. — Я работаю из дома (удалённо).
- Danas sam kod kuće. — Сегодня я дома.

### Согласование прилагательных по роду: -an/-na/-no (урок 10)

Многие прилагательные меняют окончание в зависимости от рода того, к кому/чему относятся:
- мужской род: **gladan** — *Ja sam gladan.* (Я голоден — говорит мужчина)
- женский род: **gladna** — *Ja sam gladna.* (Я голодна — говорит женщина)
- средний род: **gladno**

Та же модель дальше встретится у **umoran/umorna** (усталый/уставшая) и других
прилагательных на -an.

### jesti vs jeste — похожие, но разные слова (урок 10)

- **jesti** → я ем = **jedem** (глагол, от есть/кушать)
- **jeste** — форма глагола *biti* («быть»): «вы есть» / вежливое «да, это так»

Легко перепутать на слух — разные глаголы, разный смысл.

### Будущее время: ću/ćeš/će + инфинитив (урок 11)

Будущее строится короткими формами глагола *hteti* (от знакомого **hoću**) + инфинитив:

| | |
|---|---|
| ja **ću** | я буду |
| ti **ćeš** | ты будешь |
| on/ona **će** | он/она будет |
| mi **ćemo** | мы будем |
| vi **ćete** | вы будете |
| oni **će** | они будут |

- *Sutra **ću raditi**.* — Завтра я буду работать.
- *Sutra **će biti** toplo.* — Завтра будет тепло.
- Короткая форма любит второе место в фразе: *Ići **ću** u grad.* — Пойду в город.

### Vreme — погода и время (урок 11)

**Kakvo je vreme?** — «Какая погода?» (не «который час» — это *Koliko je sati?*).
Одно слово покрывает оба смысла: *nemam vremena* — нет времени, *lepo vreme* — хорошая погода.

### «boli me...» — что у меня болит (урок 12)

Логика как в русском «болит у меня голова»: **boli me** + то, что болит (в именительном):
- *Boli me glava.* — Болит голова.
- *Boli me stomak / grlo / zub.* — Болит живот / горло / зуб.

Если болит **несколько** предметов (мн.ч.) — глагол меняется на **bole me**:
- *Bole me oči.* — Болят глаза.
- *Bole me noge.* — Болят ноги.

Полезное рядом: *imam temperaturu* — у меня температура; *idem kod lekara* — иду к врачу;
*idem u apoteku* — иду в аптеку.

### Перфект — прошедшее время (урок 13)

Как рассказать, что ты делал. Строится почти как в русском:
**вспомогательный глагол `sam` (я) + глагол на «-o / -la»** (аналог русского «-л / -ла»).

- Мужчина: окончание **-o** → *radio, bio, jeo, pio, spavao, išao*
- Женщина: окончание **-la** → *radila, bila, jela, pila, spavala, išla*

Примеры (м.р.):
- *Juče sam **bio** kod lekara.* — Вчера я был у врача.
- *Juče sam **radio**.* — Вчера я работал.
- *Jeo sam **crni hleb** i **kuvani krompir**.* — Я ел чёрный хлеб и варёную картошку.

Спряжение вспомогательного: **sam** (я) / **si** (ты) / **je** (он-она) / **smo** (мы) / **ste** (вы) / **su** (они).

⚠️ Короткое слово **`sam/si/je...`** любит **второе место** в предложении, не начало:
- *Juče **sam** bio kod lekara.* ✅ / *Bio **sam** kod lekara.* ✅
- ~~Sam bio kod lekara.~~ ❌

### Перфект в ж.р. и мн.ч.: -la / -li (урок 14)

Меняется только окончание глагола, вспомогательный (sam/si/je/smo/ste/su) тот же:

| Кто | Оконч. | Пример |
|---|---|---|
| он | **-o** | On je **bio** |
| она | **-la** | Ona je **bila** |
| мы / они | **-li** | Mi smo **bili** / Oni su **bili** |

- *Ona je **bila** kod kuće.* — Она была дома.
- *Mi smo **bili** u kafiću.* — Мы были в кафе.

Логика ровно как в русском: был / была / были → bio / bila / bili.

### Мнение и эмоции: sviđa mi se / mislim da (урок 14)

- **sviđa mi se** = мне нравится (дословно «нравится мне себя»). Что нравится — идёт **после**:
  *Sviđa mi se Novi Sad. / Sviđa mi se ova pesma.* Отрицание: **ne sviđa mi se**.
- **mislim da...** = я думаю, что... Дальше обычная фраза с глаголом *je*:
  *Mislim da je ovo skupo. / Mislim da je Beograd velik.*
- **slažem se** = я согласен/согласна; **zato što** = потому что (причина).

### u + локатив для места — «в кафе, в России» (урок 14, повтор урок 6/8)

Где находишься → **u** (или **na**) + локатив, НЕ **kod**:
- *u kafiću, u gradu, u Rusiji, u Novom Sadu* — в кафе, в городе, в России, в Нови-Саде.
- **kod** = «у кого-то»: *kod kuće* (у дома = дома), *kod lekara* (у врача).
- Ошибка ученика: *bili smo kod kafić* → **bili smo u kafiću**.

### `da` (союз) vs `šta` (вопрос) — «что» (урок 15)

Русское «что» в сербском — два разных слова, их легко перепутать:
- **da** = союз «что» (соединяет две части): *Mislim **da** hoću kompenzaciju.* — Думаю, **что** хочу компенсацию. *Znam **da** je tako.*
- **šta** = вопросительное «что?»: *Šta hoćeš?* — Что ты хочешь? *Šta je ovo?*

После *mislim, znam, mislim da, kažem* — всегда **da**, никогда `šta`.
Ошибка ученика: *Mislim **šta** hoću…* → *Mislim **da** hoću…*

### `hoću` vs `treba mi` — «хочу» и «мне нужно» (урок 15)

Две разные конструкции, нельзя смешивать в одну:
- **hoću** = «хочу» → дальше вещь в **аккузативе** или `da` + глагол:
  *Hoću kompenzaciju.* / *Hoću **da** dobijem kompenzaciju.*
- **treba mi** = «мне нужно» → дальше вещь в **именительном**:
  *Treba mi kompenzacija.*

Ошибка ученика: *Hoću **da treba** kompenzaciju* — склеил обе. Выбирай одну.

### Как сказать «меня уволили» (урок 15)

- **Danas su me otpustili.** — Сегодня меня уволили. (перфект, `su` + `me` на 2-м месте)
- **Dobio sam otkaz.** — Меня уволили (букв. «получил увольнение») — живой разговорный вариант.
- **Ostao sam bez posla.** — Остался без работы.
- **Imam pravo na kompenzaciju.** — У меня есть право на компенсацию. (`imati pravo na` + аккузатив)
